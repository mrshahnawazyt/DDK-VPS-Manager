# DDK VPS Manager - Deploy Suite Scripts

This package contains all 5 master scripts for DDK VPS Manager:
- install.sh: Master fresh VPS auto-installer
- menu.sh: Interactive CLI terminal management menu
- rt-web.py: Python 3 web panel backend
- install-web.sh: Standalone web panel installer
- fix-xray-sync.sh: Xray sync and repair utility

## Quick Run:
chmod +x *.sh
bash install.sh
